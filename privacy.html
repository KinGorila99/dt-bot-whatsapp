Política de privacidad

Última actualización: 21 de septiembre de 2026

DT Marketing opera el bot de atención conectado a WhatsApp Cloud API para recibir y responder mensajes de clientes.

Datos que recibimos

Podemos recibir el número de teléfono, nombre visible, contenido de los mensajes y datos técnicos necesarios para entregar respuestas y mantener el historial de conversaciones en el CRM.

Cómo usamos los datos

Usamos estos datos únicamente para atender conversaciones, automatizar respuestas, mejorar el servicio y mantener la seguridad de la plataforma. No vendemos los datos personales.

Proveedores

El servicio utiliza Meta WhatsApp Cloud API, Render y Firebase para entregar mensajes y almacenar la información necesaria para la operación.

Conservación y seguridad

Conservamos la información mientras sea necesaria para prestar el servicio y aplicamos controles de acceso para protegerla.

Tus derechos

Puedes solicitar acceso, corrección o eliminación de tus datos a través del canal de contacto de DT Marketing.

Cambios

Podemos actualizar esta política cuando cambie el servicio. Publicaremos la versión vigente en esta página.
